1. Install QMM ( https://github.com/thecybermind/qmm2/wiki/Installation )
2. Make a qmmaddons/nocrash directory inside your mod directory and place nocrash_qmm.dll here
3. Add the path to nocrash_qmm.dll as an entry in the plugins list in qmm2.json
